Data Schema (SwiftData)

🔍
Issue 1 — categoryBudgetsJSON là anti-pattern
Lưu ngân sách danh mục dưới dạng JSON string mất type safety, không query được. → Tách thành entity CategoryBudget riêng.
✓ Đã sửa
🔍
Issue 2 — Thiếu ràng buộc unique (year, month)
MonthlyBudget có thể bị tạo trùng → Thêm #Unique<MonthlyBudget>([\.year, \.month])
✓ Đã sửa
🔍
Issue 3 — Ảnh lưu trong Documents bị backup iCloud
App Store Guideline 5.1.1(v): lưu file vào Application Support + isExcludedFromBackup = true
✓ Đã sửa
🔍
Issue 4 — Native TabView + Center FAB vỡ trên iOS 18
iOS 18 đổi floating tab bar → dùng Custom TabBar hoàn toàn để kiểm soát layout và VoiceOver.
✓ Đã sửa
🔍
Issue 5 — OOM khi cuộn album ảnh lớn
Dùng Image I/O downsampling + NSCache thay vì load full UIImage vào RAM. Xóa file vật lý đồng bộ với xóa SwiftData record.
✓ Đã sửa

Màu sắc & Accessibility

Đã điều chỉnh theo WCAG 2.1 AA (contrast ≥ 4.5:1 cho text nhỏ). #4CAF50 gốc chỉ đạt 2.5:1 — không đủ.

Accessibility checklist
  • Dynamic Type — tất cả Text dùng .font(.body), .headline (không hard-code size)
  • VoiceOver — mọi card/button/badge có .accessibilityLabel tiếng Việt
  • Budget warning — luôn có icon (⚠️/🚨) + text ([80%+]/[Vượt!]) bên cạnh màu
  • Tap target — tối thiểu 44×44pt cho tất cả interactive elements
  • prefers-reduced-motion — không force animation

07

Tiêu chí Nghiệm thu

  • Thêm chi tiêu có/không có ảnh → data giữ nguyên sau kill app & mở lại
  • Sửa số tiền/ngày/danh mục → cập nhật ngay ở Album + Dashboard + Budget
  • Xóa chi tiêu → tổng tiền cập nhật, file ảnh+thumbnail bị xóa khỏi disk
  • Lọc tháng → chính xác tại giao thừa 23:59→00:00 (Calendar.current)
  • Budget: 4 trạng thái hiển thị đúng (notSet / <80% / 80–100% / >100%)
  • Từ chối Camera → app không crash, vẫn cho chọn ảnh từ thư viện
  • CSV xuất đúng UTF-8, tiếng Việt, xử lý ký tự đặc biệt (comma, quote, newline)
  • Unit Tests pass: BudgetCalculator, DateHelpers ranh giới tháng, CSV edge cases
